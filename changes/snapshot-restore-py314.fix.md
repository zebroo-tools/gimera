Unter Python 3.14 schlug das Zurückspielen eines Snapshots mit "git apply ... already exists in working directory" fehl. Betroffen waren `gimera snaprestore` und `gimera apply -M` (lokale Änderungen beim Wechsel zwischen submodule und integrated mitnehmen). Zum Testen: in einem Repo mit gimera.yml eine Datei im Unterrepo ändern, den Typ in gimera.yml umstellen und `gimera apply -M` aufrufen; die Änderung muss danach ohne Fehlermeldung wieder im Unterrepo stehen.
